One-line: line chart card for a trend (1RM over time, body weight).

```jsx
<TrendChart title="1RM over time" points={[{ value: 96, label: "3 Mar" }, { value: 101, label: "18 Mar" }]} />
```

2px line, 3px points, no grid rules, transparent y-axis — same settings as the app's gifted-charts wrapper.
