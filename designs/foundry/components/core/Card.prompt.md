One-line: the standard opaque content surface — 18px continuous corners, hairline border, 16px padding.

```jsx
<Card tone="accent">
  <Eyebrow>In progress</Eyebrow>
  <AppText variant="title">Push day</AppText>
</Card>
```

Use `tone="accent"` only for a live/active object. Cards never hold form fields — use FormSection for that.
