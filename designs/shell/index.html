iOS affordances

Reads native, keeps the brand

The home indicator now sits on every screen (it's the pale bar at the very bottom — a CSS overlay here, the real system bar on device). The tab bar (visible back on every earlier screen in this set) is now the floating glass capsule from Apple's own current apps — Developer, App Store, Music — rather than an edge-to-edge bar pinned to the screen edge; back buttons are the same frosted circle. Four interaction patterns layered on top of the existing look, no chrome rebuild: swipe-to-delete on list rows, long-press context menus instead of a fourth icon button per row, the type picker as a bottom sheet, and a filter dropdown pill lifted straight from the Developer app's search-results menu.

One flag: raw iOS swipe-to-delete deletes immediately (undo via toast) — that's a different pattern from this project's baseline, which routes every destructive action through useConfirm(). Mocked below as a middle ground: the swipe reveals the action, but tapping it still opens the confirm sheet rather than deleting on the spot.
