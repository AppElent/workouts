# Historical documentation

These records preserve earlier designs, implementation plans, reviews, and
research conclusions. Their code snippets, commands, paths, counts, and status
claims describe the time of writing. Archiving does not mean every planned task
was implemented or every reported finding was resolved.

Use [the current docs index](../README.md), project standards, and source before
acting. Original document paths remain as forwarding pages so existing links
continue to resolve. Evidence with still-outstanding device acceptance remains
under `docs/reports/`, `docs/prototypes/`, or its owning design directory.
