# Workouts project guidelines

These are project-owned decisions. Shared defaults remain in
[shared guidelines](../shared/README.md) and [toolkit guides](../../features/README.md).
A deliberate override identifies its rule, scope, replacement, and reason.

- [Coding](coding.md): read before implementing or reviewing code; owns workspace boundaries, integrations, and migration exceptions.
- [Design](design.md): read for UI work; owns web identity, component seams, and design-study conventions.
- [Mobile design](mobile-design.md): also read for mobile UI; owns Foundry identity, native interfaces, interactions, and acceptance requirements.

Root [coding standards](../../../CODING_STANDARDS.md) and
[design standards](../../../DESIGN_SYSTEM.md) route to both shared and project rules.
[CONTEXT.md](../../../CONTEXT.md) owns domain vocabulary;
[ADRs](../../adr/README.md) record durable architectural trade-offs.
