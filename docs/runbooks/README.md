# Runbooks

Current project procedures. Shared setup guidance lives in the
[toolkit guides](../features/README.md); these runbooks retain Workouts-specific
identities, routing, and operational choices.

- [Environment routing](environment.md): manifest, Infisical sources, destinations, and legacy `pnpm env:*` aliases.
- [Worktree setup](worktree-setup.md): isolated Convex resources and mobile URL routing.
- [Mobile releases](mobile-releases.md): development clients, TestFlight, OTA, and runtime compatibility.
- [Mobile Sentry](mobile-sentry.md): project credentials, native builds, source maps, and version exception.
- [Exercise migration](exercise-migration.md): dry run, rollout, resume, and verification while old clients/history may need it.
- [MCP endpoint](mcp.md): Workouts tools and client authentication.
- [Issue tracker](issue-tracker.md): ticket conventions.

Use the [project verification workflow](../../.claude/skills/verify/SKILL.md)
for checks and the [verification index](../verification/README.md) for recorded evidence.
